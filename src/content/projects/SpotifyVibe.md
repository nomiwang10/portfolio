## Overview

Music is universal, but language barriers can make it difficult for listeners to fully understand songs in other languages. This project explores how AI can make music translation more immersive by combining lyric translation, emotion analysis, and image generation into one synchronized web experience.

## What It Does

- Translates Spotify lyrics into a selected target language in near real time
- Analyzes each lyric line for emotion, themes, and visual mood
- Generates an AI-created vibe board background image that matches the song’s atmosphere
- Displays the translated lyrics and generated visuals through a React front end

## Tech Stack

- **Spotify Web API** — track and playback data
- **OpenAI text models** — translation, emotion detection, and theme extraction
- **OpenAI image models** — abstract vibe board image generation
- **React** — synchronized lyric and visual display
- **Python / FastAPI** — backend API and AI service integration
