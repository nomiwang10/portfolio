## Overview

InkRush is a multiplayer drawing and guessing game inspired by Pictionary. Players join a shared game session, take turns drawing prompts, and compete by guessing the correct word in real time.

The project was developed as the final project for **ECE:3330 Intro to Software Design** and focuses on applying object-oriented design, networking, concurrency, and database-backed game logic in a complete Java application.

## Features

- Real-time multiplayer drawing and guessing gameplay
- JavaFX-based user interface
- TCP socket communication between client and server
- Multithreaded server design for handling multiple players
- Database-backed word system for managing drawing prompts
- Turn-based game flow with synchronized player interactions

## Tech Stack

- **Java**
- **JavaFX**
- **TCP Socket Networking**
- **Multithreading**
- **Database-backed word management**
